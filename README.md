# AI Career & Placement Copilot

AI Career & Placement Copilot is an intelligent career assistant designed to help students and job seekers prepare for placements and job applications. The platform provides personalized career guidance, resume analysis, job recommendations, and AI-powered mock interviews.

## Features

### Resume Analysis
- Upload resume in PDF format
- Extract key skills and information
- Identify strengths and improvement areas

### Job Recommendations
- Personalized job suggestions based on skills
- Career path recommendations
- Skill-gap analysis

### AI Mock Interviews
- Dynamic interview questions
- Voice interview mode
- Real-time response evaluation
- Interview practice for different job roles

### Speech-to-Text Support
- Voice-based responses
- Automatic transcription
- Hands-free interview experience

### Career Guidance Chatbot
- AI-powered career advice
- Placement preparation tips
- Learning resource recommendations
